# Product Images — Upload Instructions

Place your produce images in this folder using the **exact filenames** listed below.
The landing page ProduceGrid reads images directly from this path.

## Required files

| Filename             | Crop           | Notes                          |
|----------------------|----------------|--------------------------------|
| `cabbage.jpg`        | Cabbage        | Use a fresh, well-lit photo    |
| `green-bananas.jpg`  | Green Bananas  | Bunch shot preferred           |
| `peppers.jpg`        | Peppers        | Mixed red/green works well     |
| `tomatoes.jpg`       | Tomatoes       | Cluster or single close-up     |
| `irish-potatoes.jpg` | Irish Potatoes | Pile/crate shot preferred      |
| `eggplant.jpg`       | African Eggplant | Single or group               |
| `hero-bg.jpg`        | Hero background | Wide landscape, 1920×1080+    |

## Supported formats
`.jpg` / `.jpeg` / `.png` / `.webp`

## Fallback behaviour
If an image file is missing, the card shows a colour-coded gradient
placeholder with the crop's initial letter — so the page still renders
correctly before you upload real photos.

## Recommended dimensions
- Product cards: **800 × 600 px** minimum, 4:3 ratio
- Hero background: **1920 × 1080 px** minimum, landscape

## Privacy note
These are product/produce images only. Never upload photos that reveal
a farmer's face, home, or identifiable location details.
